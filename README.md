# AI Software Engineering Agent

An AI agent that can inspect an existing codebase, plan changes, modify code, run tests, analyze failures, self-correct, and prepare final changes for human review.

## Goal

Build a production-style software engineering agent that can:

* Understand software tasks
* Inspect existing repositories
* Select and use development tools
* Make controlled code changes
* Run tests and lint checks
* Fix failures automatically
* Generate a final Git diff
* Request human approval for important actions

## Tech Stack

* Python
* OpenAI Agents SDK
* Groq API
* FastAPI
* PostgreSQL
* Docker
* Git
* pytest
* Ruff
* React + Vite

## Status

🚧 **Currently under development**

The project is being built in phases, starting with the backend foundation, task management, repository tools, agent integration, sandboxed execution, and approval workflow.
